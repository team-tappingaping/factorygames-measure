# FactoryGames 원격 측정

FactoryGames(공장 테마 인지·운동 기능 측정 게임 시리즈) 과제를 각자 PC에서 측정하기 위한 배포판입니다.
Unity 소스 코드는 들어있지 않고, WebGL로 빌드된 결과물만 올려둔 저장소예요.

## 사용 방법

1. **https://team-tappingaping.github.io/factorygames-measure/** 접속 (Chrome 또는 Edge 권장. Safari/Firefox는 기기 연결이 안 돼요)
2. 참가자 코드 입력, 측정하는 손 선택
3. 과제 카드 중 하나 클릭 → 게임 로딩 → 측정 진행
4. 측정이 끝나면 **결과 CSV 파일이 자동으로 다운로드 폴더에 저장돼요**
   - 처음 한 번은 브라우저가 "여러 파일 다운로드를 차단함" 알림을 띄울 수 있어요. 주소창 오른쪽 아이콘 눌러서 **허용**해주세요.
5. 화면 왼쪽 위 "메뉴로 돌아가기"를 누르면 다른 과제도 이어서 측정할 수 있어요 (코드/손은 다시 입력 안 해도 됨)
6. 측정 끝나면 **다운로드된 CSV 파일들을 그대로 보내주세요** (파일 이름에 참가자 코드가 없어도, 내용 안에 들어있어서 구분돼요)

## 포함된 과제 (9개)

| 과제 | 설명 |
|---|---|
| FTT | 손가락 두드리기 |
| Go/No-Go | 출고 게이트 |
| SART | 컨베이어 |
| Eriksen (Flanker) | 창고 표지판 |
| N-back | 검사실 모니터 |
| Simon | 제어실 콘솔 |
| Tracking | 유압 압력계 |
| PVT | 야간 신호등 |
| ForceControl | 조립 작업대 |

## 참고

- HANDGRIP 기기 없이 터치/마우스로도 테스트는 가능하지만, 실제 측정은 기기를 연결해서 해주세요.
- 처음 로딩할 때 콘솔에 "Content-Encoding: gzip" 관련 경고가 떠도 정상이에요. 로딩이 조금 느려질 뿐 동작엔 문제없어요.
- 기기 연결은 Web Serial을 쓰기 때문에 HTTPS에서만 돼요 (이 사이트는 HTTPS라 문제없음).
